# Signal & Systems Laboratory (MATLAB)

This repository contains my implementations and experiment codes from **ECE 2108: Signal & Systems Laboratory**.  
All codes are written in **MATLAB** and organized by experiment, following the official lab manual structure.

---

## 📘 Overview
The repository demonstrates fundamental concepts of signals and systems using MATLAB, including:
- Signal generation and plotting
- Function definitions and signal decomposition
- Shifting and phase operations
- Verification of Euler’s equation
- Statistical analysis of signals
- Fourier series, Fourier transform, convolution, correlation
- Laplace & Z-transform, system stability
- State-space models (continuous & discrete)

---


## 🚀 Getting Started
### Prerequisites
- MATLAB R2018a or later
- Signal Processing Toolbox (recommended)

### Running the Code
1. Clone the repository:
   ```bash
   git clone https://github.com/arafat-siju/MATLAB-Practice.git
2. Open MATLAB and set the current folder to the cloned repo.

3. Navigate to the desired experiment folder.

4. Run the  .m  files using:
     ```bash
      run('filename.m')
---

## 📊 Key Highlights
**Experiment 01:** Introduction to MATLAB and different singularity functions generation and plotting.

**Experiment 02:** Study on MATLAB function, shifting of signal, verification of Euler’s equation, some statistical MATLAB function and solution of linear set of equation.

**Experiment 03:** Study on Fourier series & Fourier transform, correlation & convolution of signals, solution of differential equations, and parallel & cascaded systems.

**Experiment 04:** Experiment on linearity and time variance of a system, Laplace & Z transform and stability of a system.

**Experiment 05:** Study on Continuous and Discrete State Space Model.
